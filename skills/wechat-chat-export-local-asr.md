- **项目类型**：GitHub 开源项目，Apache-2.0；第三方依赖按各自许可证使用。
- **验证状态**：用户已在 Windows 上成功导出微信聊天，并通过本地 SenseVoice 将语音转成文字。

本案例记录可复用的工具与流程，不包含真实聊天、数据库、密钥、媒体或转写结果。

## 2. 核心能力

将本机可读取的微信聊天导出到本地，再将语音消息通过本地语音识别（ASR）转成可检索文字，为个人归档、后续整理或经授权的数据分析准备输入。

**用户已验证**：Windows 环境下的聊天导出与本地 SenseVoice 转写。

**上游文档说明**：提供 TXT、Markdown、JSON 输出，并支持按选项处理本机仍有缓存的媒体。本案例未逐项验证输出格式、全部消息类型或媒体完整性，也不将上游功能列表等同于用户测试结果。

## 3. 收录价值

### 3.1 把聊天与语音变成可继续处理的数据

聊天导出解决数据获取问题，本地语音识别补充语音消息中的文字信息。两者衔接后，可以为检索、阅读和分析准备材料；这些后续应用尚未在本案例中验证。

### 3.2 保留本地处理流程

根据上游说明，导出和语音识别在本机进行，首次启用转写需要下载模型。将导出结果交给云端大模型属于另一个数据流转步骤，需要另行判断授权、脱敏和上传范围。

### 3.3 积累可复用的部署经验

模型不必与 EXE 放在同一目录。识别能够运行但安装目录找不到模型时，应检查当前 Windows 用户的应用数据目录，并区分模型文件、转写缓存与敏感解密临时缓存。

## 4. 使用场景

- 归档本人有权访问和处理的微信聊天。
- 将聊天中的语音转成文字，便于后续本地阅读和检索。
- 为经授权、脱敏后的聊天整理或分析准备材料。

### 4.1 Windows 环境

| 项目 | 已知信息 |

| 用户实际验证 | Windows；具体系统版本未记录 |
| 上游目标环境 | Windows 微信 4.1.12+；不代表所有后续版本均已验证 |
| 上游源码运行建议 | Windows 10 / 11、Python 3.12 |
| Windows EXE | 上游提供单文件程序，无需另装 Python；用户实际采用的安装方式未记录 |
| 微信状态 | 按上游流程，先登录 Windows 微信并保持运行 |

下列流程与默认路径来自上述上游文档，是复用指引；不表示用户逐项执行过所有步骤，也未在本次文档整理中重新运行程序。

### 4.2 关键流程

1. 从原项目的 [Releases](https://github.com/zhuzhangxue/wechat-chat-export/releases) 获取 Windows 版本，并记录工具及微信版本。源码运行方式见上游 README。
2. 登录 Windows 微信，确认目标聊天在本机可用。
3. 打开工具，输入准确的好友备注、昵称或群名；有多份数据目录时核对所选账号与目录。
4. 按需选择媒体，启用「语音转文字（本地）」。根据上游说明，此选项会同时导出语音；首次使用需要下载 SenseVoice 模型。
5. 开始导出，在本地检查生成的聊天文件及转写内容。抽查发送者、时间顺序和语音原意，保留无法确认的内容，不将识别结果直接当作准确原文。
6. 后续分析前先确认处理权限、删减无关内容并脱敏；导出完成后检查敏感缓存是否清理。

上游给出的会话输出文件名为 `chat_full_for_llm.txt`、`chat_full_for_llm.md` 和 `chat_full_parsed.json`；媒体按类型放在 `media/` 下。实际结果应以所用版本和导出日志为准。

### 4.3 本地模型与缓存位置

以下为上游默认位置，尚未核实用户电脑上的实际路径。可将路径粘贴到 Windows 的「运行」（Win + R）或资源管理器地址栏；`%LOCALAPPDATA%` 和 `%TEMP%` 随当前 Windows 用户变化。

| 内容 | 默认位置 | 注意事项 |
| --- | --- | --- |
| SenseVoice 模型 | `%LOCALAPPDATA%\WeChat-Chat-Export-for-LLM\models\sensevoice` | 首次下载约 230 MB 的 SenseVoice Small Int8；模型不打包在 EXE 内，换新版 EXE 后可复用 |
| 语音转写缓存 | `%LOCALAPPDATA%\WeChat-Chat-Export-for-LLM\cache\voice_asr_cache.json` | 含聊天转写文字；重复导出可复用，应按敏感聊天数据保护 |
| 源码运行时下载的语音解码器 | `%LOCALAPPDATA%\WeChat-Chat-Export-for-LLM\tools\rust-silk.exe` | 用于 SILK → WAV；上游正式 Windows EXE 已包含解码器 |
| 敏感临时工作目录 | `%TEMP%\wechat-chat-export-sensitive\run-...` | 可能含解密密钥及明文数据库缓存；不同于模型缓存 |

找不到模型时，先核对当前登录的 Windows 用户和上述目录，避免只在 EXE 旁寻找。首次模型下载需要联网，不应把“本地识别”理解为从安装起全程不联网。

## 6. 局限与注意事项

- **数据权限与隐私**：仅处理本人有权访问和处理的数据，尊重聊天参与者的隐私。真实聊天、微信数据库、解密密钥、媒体和转写缓存不得提交到本能力库；排障材料也需先脱敏。
- **本地处理的边界**：上游声明工具不上传聊天内容、语音识别在本机完成；本案例未作独立网络或安全审计。首次模型、依赖或工具下载仍涉及网络。
- **三类缓存分别管理**：模型文件用于推理，转写缓存含聊天文字，敏感临时缓存可能含密钥和明文数据库。清除敏感缓存不等于删除导出文件或转写缓存。
- **敏感缓存清理**：上游 v1.3.4 起使用一次性工作目录，并尝试在正常结束时删除；强制退出、断电或文件占用仍可能留下残余，运行期间也可能存在明文。可按上游说明使用「清除敏感缓存」。旧版 `%TEMP%\wechatauto_db` 可能与其他工具共用，清理前先确认占用及影响范围。
- **媒体与历史完整性**：只能处理本机现存数据；已清除的媒体不能据此恢复。不要将“导出成功”解释为历史聊天和所有附件均完整。
- **解析与识别误差**：同名联系人、错误数据目录、特殊消息、发送者映射和语音识别都可能影响结果；重要内容需要对照原记录。
- **兼容性**：微信及上游依赖更新可能使流程失效。升级后应先用小范围数据检查，不将本次成功推广到所有版本或其他操作系统。
- **来源与许可**：本条目是第三方项目的使用案例；使用和分发原项目及其依赖时，应查看原项目许可证与第三方声明。
